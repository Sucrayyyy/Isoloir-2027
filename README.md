# Isoloir 2027

Choisis des idées, pas des noms. Une app web neutre pour la présidentielle 2027 : tu tranches des propositions anonymes des candidats, puis l'app révèle le programme le plus proche de tes réponses.

- Test express (32 idées) et test complet (77 idées)
- Programmes à l'aveugle (16 programmes, identité révélée à la fin)
- Installable sur l'écran d'accueil (Safari > Partager > Sur l'écran d'accueil), fonctionne hors connexion
- Aucune donnée envoyée : tout reste dans le navigateur

Données : `data.js` (positions à jour au 6 novembre 2026, sources dans l'app, page Méthode).
